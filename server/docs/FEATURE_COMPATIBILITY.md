# Feature compatibility

The compatibility matrix distinguishes BACKEND_VERIFIED, PIXEL_VERIFIED, PARTIAL, BLOCKED and NOT_TESTED. See [KNOWN-ISSUES.md](KNOWN-ISSUES.md) for the remaining gaps. Historic migration coverage remains in [FEATURE_PRESERVATION.json](FEATURE_PRESERVATION.json); those validations are not new Android tests.

M25 is not fully complete or normally deployed. Timed branching, Collection acquisition variants, complete gates through 80, pending rewards, medal bonuses and fresh Raid/Rocket/Max native regression need further acceptance. Branch choice cards remain a native binding issue even though confirmation/selection/persistence works.
