Streets & map data

0 cells

OpenStreetMap cells download automatically, one small area at a time, when a trainer plays: the cell under the player is fetched before the map reply, then the server keeps walking outward ring by ring for as long as it runs, so distant streets fill in over time. Generated tiles are saved under data/maps/tile-cache and served from disk. Small streets, service roads, tracks and footpaths are included, not just main roads.
